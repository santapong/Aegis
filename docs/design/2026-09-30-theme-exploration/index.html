1 · Warm Ivory

The warmer companion to Meridian. It feels calm for planning, while white panels keep forms and numbers crisp.

Same layout, typography, icon, and content in both modes. The darker amber and teal text colors keep labels readable on light surfaces; amber buttons keep dark text.

Behavior when implemented

Light / Dark / System

  • Appearance belongs in the header and Settings.
  • System follows the device; an explicit choice takes priority.
  • Switching keeps forms, drafts, selections, and scenarios intact.
  • Inputs, errors, menus, code blocks, and charts all use the chosen mode.
  • The existing dark icon stays unchanged in its quiet dark tile.

These are proposed production behaviors. This board uses local preview controls and does not change your Aegis settings.
